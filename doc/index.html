vis-python-runtime

Embed CPython in Java and Clojure. Run Python expressions, keep session state, and expose host functions through a small native bridge.

Java APIJavadoc for the interpreter, native loading, callbacks, and supporting types. Clojure APICodox reference for functions, argument maps, and return values.

Start with a working example

The getting-started guide covers the JVM jar, native archive, Java and Clojure setup, and expected output. You can also download the runnable Java example.

Choose the right execution and isolation model

Sessions keep separate globals, but share one interpreter, imports, and the GIL. A session is not a process or a security boundary. Read embedding and confinement before running untrusted code.

Windows x64 supports the embedded runtime. OS-level child-process confinement is not available on Windows; jail requests fail rather than run without enforcement.
